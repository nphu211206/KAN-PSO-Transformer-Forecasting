# KAN Grid-Update Reliability Study

This repository contains the public code, manuscript source, figures, derived tables, audits and reproducibility metadata for the study. The immutable release manifest identifies every copied file by SHA-256.

The K10 archive is intentionally not stored in ordinary Git history because GitHub rejects files over 100 MB. It should be deposited in Zenodo and linked here after DOI creation. Do not infer missing evidence from this GitHub tree alone; use the DOI-bearing archive for the complete release.
